# 家教筛客 · WeChat Tutor Filter

**少翻群消息，把时间留给值得接的家教。**

家教群消息太多，同一份订单反复转发；好不容易找到报价合适的，又发现时间冲突、教师要求不符，或者通勤太远。

家教筛客帮你把这些信息整理成一份**按你的条件筛选的本地清单**。告诉 Agent 你想教什么、什么时候有空、期望时薪和能接受的通勤时间，它就能帮你配置并运行筛选，你再从候选中决定联系谁。

## 它能帮你解决什么

| 你的困扰 | 家教筛客如何帮忙 |
| --- | --- |
| 群消息刷得太快，看不过来 | 从你指定的家教群中提取订单，集中展示 |
| 同一个订单发了很多遍 | 拆分批量订单、合并重复信息，保留最新发布内容 |
| 每条都要检查年级、科目和价格 | 按你的授课范围、时薪要求和个人条件自动筛选 |
| 报价合适，但时间对不上 | 对照每天可授课的时间区间检查冲突 |
| 地址看着不远，实际坐车很久 | 对符合其他条件的候选查询高德公共交通预计耗时 |
| 不知道为什么没被推荐 | 展示具体排除理由，把信息不足的订单列为待确认 |
| 想留几个比较，又不想反复看到已接走的单 | 加入待选、标记熄单，并保存反馈供后续筛选使用 |

你得到的是一份可在浏览器打开的报告：**推荐、待确认、待选和排除原因一目了然**，需要时可以展开对应原文核对。支持亮暗主题，也可以在报告里调整已支持的偏好。

## ⚠️微信账号风险提示

本项目并非微信官方工具，消息读取涉及微信进程及本地数据库，可能触及微信对第三方工具使用的限制，**存在账号被限制使用或封禁的风险**。即使仅在本地读取、不自动发送消息，也不能保证账号安全。目前没有可靠数据评估具体封号概率，过往正常运行不代表后续无风险。**若无法接受账号受限的后果，请勿启用微信读取功能。**

使用前请阅读[腾讯微信软件许可及服务协议](https://oper.my-qcloud.com/cgi-bin/readtemplate?lang=zh_CN&s=default&t=weixin_agreement)。

## 最简单的开始方式

你需要一台 **Windows 电脑**、已登录的桌面微信，以及能访问本地文件、执行命令的 **Codex Agent**。无需提前学习 Python 或手动编辑配置文件。

### 1. 把这句话发给 Agent

```text
请帮我安装并使用家教筛客：
https://github.com/Caspainnn/Totur-Filter

先阅读仓库中的 skills/wechat-tutor-filter/SKILL.md，
1. 按照 Skill 检查并配置本地环境
2. 展示用户偏好模板文件并引导我填写
3. 完成首次筛选并打开网页
```

环境检查、依赖安装、路径和配置处理交给 Agent。你只需配合完成它无法替你决定或操作的事项。

### 2. 告诉它你想接什么家教

根据 Agent 的引导填写偏好文件，主要包括：

- **从哪里找**：允许读取的家教群完整名称。
- **你能教什么**：本人条件、教学经验、接受的年级和科目。
- **什么订单合适**：最低时薪、每周可授课时段。
- **愿意去多远**：出发地点、城市、最长单程通勤时间。

需要核实线下通勤时，按引导申请自己的高德地图 Key，并在本机安全录入，**不要把 Key 发进聊天**。暂未配置地图时，可以先检查其他条件，但线下通勤尚未核实。

### 3. 打开报告，挑选候选

Agent 完成运行后会提供报告入口。你可以查看推荐和待确认订单、加入待选、标记已被接走的订单。

修改偏好或标记熄单后，按页面提示**保存更改到项目目录**，后续运行才会读取这些变化。如果浏览器只下载了文件，需要将文件放到项目目录；Agent 可以引导你完成。

## 以后怎么用

直接对 Agent 说：

> 使用家教筛客，按我当前的偏好重新筛选，打开最新报告。

想调整条件：

> 我现在周三晚上也有空，最低时薪改为 120 元。请更新偏好并重新筛选。

想定时查看：

> 每天北京时间 12:00 帮我筛选一次，已有计划就更新，不要重复创建。只有新增有意义候选、失败或需要我处理时通知。

定时运行需要电脑、Codex 和微信保持可用。安装 Skill 本身不会创建计划。

## 使用前了解这些

- **读取范围由你决定。** 仅查询白名单群，不提供私聊查询，不自动发消息、联系客户或代接单。
- **日常筛选在本机完成。** 不需要把订单逐条发送给外部 AI API；地图查询只发送必要的地点、坐标和时间信息。本地报告可能包含私人信息，请勿公开分享真实报告。
- **推荐是筛选结果。** 订单是否仍可接、最终报酬和课程安排需要本人确认；地图耗时是预计值，地标附近的路线会标明参考目的地。
- **兼容性有范围。** 现有环境验证的微信版本为 Windows 4.1.15.53，主要使用场景在北京，其他版本和城市需要 Agent 核实支持情况。
- **当前正在整理开源部署流程。** 首次安装仍可能需要 Agent 处理路径和初始化配置，尚未完成全新电脑的一键部署验证。
